Publish on GitHub Pages

This tool is a single self-contained index.html — no server, no build step. That is exactly what GitHub Pages serves.

  1. Download the file with the button below.
  2. Create a new public repository on GitHub, e.g. video-ads-analyzer.
  3. Upload index.html to the root of the repository and commit.
  4. In the repo: Settings → Pages → Deploy from a branch → main / (root), then Save.
  5. After about a minute the tool is live at https://<your-username>.github.io/video-ads-analyzer/
# Video Ads Analyzer — Macsara Hair A single-file web tool for planning Meta (Facebook / Instagram) video ads in the 3:2:2 Flexible Ad format. ## What it does - Add ad videos by link (YouTube, TikTok, Drive) or file upload - Scans each clip and detects the hair product shown — type, shade, texture - Maps the detected product to the shop.macsarahair.com catalog snapshot built into the file (name, real price, product link) - Scores every video: hook, clarity, trust, closing power + suggested Ring 1–5 - Groups videos into trios (3 creatives per group) - Generates 2 primary texts + 2 headlines per group, 100% in English, using the mapped product's real price ## Run it Open `index.html` in any browser, or enable GitHub Pages: Settings → Pages → Deploy from a branch → main / (root). No build step, no server, no dependencies. Catalog snapshot: see the Shop Catalog tab inside the tool.
Catalog source: shop.macsarahair.com · Analysis runs locally in your browser from the details you enter for each clip — the fuller the transcript, the sharper the scan, scores and copy.
