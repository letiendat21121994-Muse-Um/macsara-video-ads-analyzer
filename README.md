# Macsara Video Ads Analyzer

Video Ads Analyzer for Macsara Hair — analyze Meta ad videos, group them in trios of 3 (3:2:2), detect products and map them to shop.macsarahair.com, and generate 2 primary texts + 2 headlines in English per group.

Live site: https://letiendat21121994-muse-um.github.io/macsara-video-ads-analyzer/

## How to use

1. Open the live site above, or download `index.html` and open it in a browser.
2. Add videos by link (YouTube / TikTok / Drive) or file upload.
3. Click **Analyze all videos** — each video is scored on hook, clarity, trust and closing power, with strengths, fixes and a suggested Ring 1–5.
4. The product scanner detects the hair type, shade, texture and length in each clip and maps it to a real product on shop.macsarahair.com, with its real price and product link. The Shop Catalog tab lists the products synced from the shop.
5. Group videos in trios of 3 — auto-group or hand-pick exactly 3. Each trio generates 2 primary texts + 2 headlines in English, grounded in the matched product and its real price.
6. Edit, copy, or export the copy as a `.txt` file for Ads Manager.

## Notes

- 100% English content.
- This is a static single-file app (`index.html`). The video library is kept in the open browser session only — there is no server storage.
